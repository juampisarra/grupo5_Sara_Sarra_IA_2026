# grupo5_Sara_Sarra_IA_2026

Repositorio para las entregas de Inteligencia Artificial 2026.

## Entrega 1

Archivos requeridos por la catedra:

- `entrega1.py`: implementacion principal.
- `entrega1_por_ia.py`: solucion generada con asistencia de IA para comparar.
- `conclusiones_entrega1.md`: conclusiones de la comparacion.

## Entorno

Crear e instalar dependencias:

```powershell
python -m uv sync
```

Ejecutar tests, luego de ubicar `test_entrega1.py` en la raiz del repo:

```powershell
python -m uv run pytest -v
```

Ejecutar tests con mas salida de debug:

```powershell
python -m uv run pytest -vvv -s
```
